# useAnimations assets

These Lottie JSON files were obtained from the
[useAnimations repository](https://github.com/useAnimations/react-useanimations)
at commit `f7af6f53f6f1a97486ad95756b281a34e9f7c670`.

The original filenames are preserved: `loading` (Loading circular), `edit`,
`terminal`, `alertTriangle`, and `checkmark`. The files are distributed under
the MIT license reproduced in `LICENSE`. The stroke widths are increased from
2 to 2.3 units for legibility in the macOS menu bar.
